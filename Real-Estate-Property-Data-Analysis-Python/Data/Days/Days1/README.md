# Day 01 - Understanding the Dataset

## Objective

The goal of Day 1 is to understand the structure and basic information of the real estate dataset using Python and Pandas.

## Tasks Completed

- Imported Pandas
- Loaded the Excel dataset
- Viewed the first 5 rows using `head()`
- Viewed the last 5 rows using `tail()`
- Viewed random records using `sample()`
- Checked dataset shape using `shape`
- Inspected column names
- Checked data types
- Reviewed dataset information using `info()`
- Generated summary statistics using `describe()`

## Dataset

- Rows: 300
- Columns: 7
